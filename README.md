# turki-family — دفتر العزيمة

دفتر عربي من اليمين إلى اليسار لإدارة معازيم العرس من الهاتف. لا يحتاج إلى حساب أو كلمة مرور. أضف الاسم واللقب، واجعل الهاتف اختيارياً، وحدد عدد أفراد المجموعة ومن سيتولى العزيمة.

## تشغيل سريع

```powershell
npm install
npm run dev
```

من دون إعداد Supabase يعرض التطبيق بيانات تجريبية ويحفظ أي تعديلات على الجهاز الحالي فقط.

## تفعيل المشاركة بين هواتف العائلة

1. شغّل ملف `supabase/migrations/202610090001_guest_registry.sql` مرة واحدة في SQL Editor للمشروع الصحيح.
2. انسخ `.env.example` إلى `.env.local` وأضف رابط Supabase والمفتاح العام:

   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-public-publishable-key
   ```

3. أعد تشغيل `npm run dev` أو أنشئ نسخة النشر بـ `npm run build`.
4. من هاتف واحد أنشئ دفتر العائلة وشارك رابطه مع أفرادها؛ يُفتح الدفتر على هواتفهم دون تسجيل دخول.

ملف `.env.local` مستثنى من Git. استخدم المفتاح العام فقط، ولا تضع مفتاح `service_role` في الواجهة. ملف الترحيل يضيف جداول ووظائف تخص هذا التطبيق، ولا يغير إعدادات تسجيل الدخول أو السياسات الموجودة على جداول أخرى في المشروع.

## ما يوفره التطبيق

- تصميم عربي ملائم للهاتف، مع جدول على الشاشات الواسعة وبطاقات واضحة على الهاتف.
- إضافة وتعديل الأسماء، مع لقب اختياري ورقم هاتف اختياري.
- عدد أفراد المجموعة يشمل الاسم المسجل، ويُجمع لإظهار إجمالي المدعوين وأفراد عائلاتهم.
- اختيار «من طرف»: شهاب، هاشم، صلاح، إسماعيل، أو محمد.
- تسجيل «تمت العزيمة» أو «لم يرد» وإضافة ملاحظات وسجل للتواصل.
- بحث بالاسم أو الهاتف، وتصفية حسب الحالة أو الشخص، وفرز حسب الاسم أو حجم المجموعة أو الشخص أو آخر تحديث.
- اكتشاف الاسم أو رقم الهاتف المكرر، وسجل CSV للتنزيل.
- دفتر مشترك بين الهواتف مع تحديث فوري ومحاولة استعادة البيانات عند عودة الاتصال.

حجم المجموعة الافتراضي شخص واحد، ويمكن ترك الهاتف واللقب فارغين. الاسم الأول وعدد المجموعة و«من طرف» هي الحقول الأساسية.
