# أفراح عائلة التركي

دفتر عربي مشترك لإدارة معازيم العرس من الهاتف، دون تسجيل دخول. يفتح جميع أفراد العائلة القائمة نفسها تلقائياً، وتبدأ فارغة دون بيانات تجريبية.

## المميزات

- إضافة سريعة: الاسم مطلوب، واللقب والهاتف و«من طرف» اختيارية.
- الأشخاص المتاحون: شهاب، هاشم، صلاح، إسماعيل، محمد.
- عدد المجموعة يشمل المعزوم نفسه؛ إجمالي المدعوين هو مجموع الأشخاص، وليس عدد السجلات.
- منع تكرار الاسم الكامل أو رقم الهاتف، مع توحيد الحروف والأرقام العربية وصيغ الهاتف الليبي.
- البحث بكلمات متعددة في الاسم والهاتف والشخص، والتصفية حسب الشخص والحالة.
- الفرز تصاعدياً وتنازلياً بالاسم، وعدد الأشخاص، والشخص، والحالة، وآخر تحديث.
- تسجيل «تمت العزيمة» أو «لم يرد»، وإضافة ملاحظات من تفاصيل المعزوم.
- مزامنة مباشرة بين الهواتف، وتحديث دوري للاستعادة عند انقطاع الاتصال.
- جدول على الشاشات الواسعة وبطاقات سهلة اللمس على الهاتف، وتصدير النتائج إلى CSV.

## قاعدة البيانات

المشروع مربوط بـ `oxlsxignqmhimasfenoe.supabase.co`. رابط المشروع والمفتاح العام موجودان كإعداد افتراضي للواجهة؛ يمكن تجاوزهما بمتغيري `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` كما في `.env.example`.

تم تطبيق `supabase/migrations/202610090001_guest_registry.sql` على المشروع. ينشئ الجداول ووظائف الدفتر المشترك ومنع التكرار وتحديث الحالات وإشعارات المزامنة. لا يحتوي على تغيير إعدادات تسجيل الدخول أو سياسات RLS أو أوامر GRANT/REVOKE.

تُستخدم `open_turki_book` لفتح الدفتر، و`get_turki_snapshot` لجلب القائمة والسجل في استجابة واحدة دون حد الصفوف الافتراضي. يحتاج حفظ التعديلات إلى اتصال بالإنترنت؛ لا تُعرض بيانات محلية وهمية عند تعذر الاتصال.

## Vercel

استورد مستودع `mturke1996/turki-family`، واختر فرع `main`. ملف `vercel.json` يحدد إعدادات Vite تلقائياً: التثبيت `npm ci`، والبناء `npm run build`، والمخرجات `dist`. لا تحتاج لإضافة متغيرات البيئة لاستخدام مشروع Supabase الحالي.

رفع الكود إلى GitHub مستقل عن إنشاء نشر ناجح على Vercel. بعد النشر، شارك رابط الموقع نفسه مع جميع أفراد العائلة.
